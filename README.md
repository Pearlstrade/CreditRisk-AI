# AI-04 — Loan Default Risk Predictor

A complete beginner-to-intermediate machine-learning MVP for estimating the likelihood that a micro-loan applicant may default.

> **Important:** This project uses a clearly documented **synthetic Nigerian micro-lending dataset** generated for learning and demonstration. It is **not** a credit bureau, banking, or production underwriting system. Do not use the model to automatically approve/deny real applicants without proper validation, legal review, bias testing, explainability, data protection controls, and human oversight.

## Project-bank alignment

- **Brief:** AI-04 — Loan Default Risk Predictor
- **Problem context:** Micro-lenders and POS agents need quick repayment-risk checks.
- **MVP:** Tabular model predicting likelihood of loan default.
- **Features:** Manual/CSV input, risk score, key factors, confusion matrix/evaluation.
- **Deliverables:** Dataset, training pipeline, trained model, evaluation, README, Streamlit app, Dockerfile and deployment configuration.

## Run locally

### 1. Create an environment

Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Generate the dataset

```bash
python src/generate_data.py
```

### 4. Train and evaluate

```bash
python src/train.py
```

This creates:

- `model/loan_default_pipeline.joblib`
- `model/model_metadata.json`
- `model/metrics.json`
- `model/confusion_matrix.png`
- `model/roc_curve.png`
- `model/feature_importance.csv`

### 5. Run the application

```bash
streamlit run app.py
```

Open the local URL printed by Streamlit, normally `http://localhost:8501`.

## CSV prediction

The app also accepts a CSV with the feature columns listed above. The file must contain one or more applicant rows. A downloadable template is generated by the app.

## Model selection

The training script compares Logistic Regression and Random Forest using ROC-AUC on a validation set, then evaluates the selected model on a held-out test set. The saved threshold is chosen on the validation set using the F1 score, rather than assuming 0.50 is always optimal.

## Risk bands

- **Low:** score < 30
- **Medium:** 30–60
- **High:** > 60

These bands are product UX labels, not regulatory credit grades.

## Deployment

### Streamlit Community Cloud

1. Create a GitHub repository.
2. Upload this project.
3. Make sure `requirements.txt`, `app.py`, `model/loan_default_pipeline.joblib`, `model/model_metadata.json`, and `model/feature_importance.csv` are committed.
4. In Streamlit Community Cloud, create a new app.
5. Select the repository and branch.
6. Set the main file to `app.py`.
7. Deploy.

### Docker

Build:

```bash
docker build -t ai04-loan-risk .
```

Run:

```bash
docker run -p 8501:8501 ai04-loan-risk
```

Then open `http://localhost:8501`.

## Production roadmap

Before real lending use:

1. Replace synthetic data with consented, representative historical lending data.
2. Establish a legally valid target definition and observation window.
3. Remove leakage and post-loan variables.
4. Test performance by gender, age group, location, income band and other legally relevant groups.
5. Validate calibration and stability over time.
6. Add model monitoring, drift detection and audit logs.
7. Add authentication and role-based access.
8. Encrypt sensitive data and minimize PII.
9. Keep a human decision-maker in the loop.
10. Obtain legal/compliance review for Nigeria and the exact lending product.
